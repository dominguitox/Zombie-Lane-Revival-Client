## Provenance of the port

The maintainer says the port was AI-generated from the patched IPA; that account is unverified. [hypothesis: port]

`platform-1001.jar` contains `META-INF/zlport/game-core.properties` with the text "generated by zlport.apkimport"; this suggests an Android APK may also have been used, but the input and version are unknown. [hypothesis: port]

The exact APK or IPA and version used as input remain unknown. [hypothesis: port]

## Evidence labels

Claims use the labels defined in [evidence-labels.md](./evidence-labels.md):

- `[verified: play]` means observed in a running game and recorded in a dated
  log.
- `[verified: docs]` means supported by official, first-party documentation.
- `[verified: clean-apk]` is reserved for a clean-APK baseline that has not been
  obtained.
- `[code-read: <source>]` means read from decompiled code, bytecode, or supplied
  build files, without running them.
- `[hypothesis: <source>]` means inferred from the IPA, port, Flash build, or
  Android material.
- `[implemented]` and `[smoke-tested]` apply only to this repository's own
  server and launcher work.
- `[not exercised in a live session]` is a legacy qualifier, not an evidence
  label.

The old `[observed: Flash]` label was migrated to
`[code-read: flash-decompile]`. The old `[observed: port]`, `[observed: docs]`,
`[observed: Wayback]`, and `[observed: Web]` labels remain only where their
meaning could not be mapped without guessing. The `[corroborated]` label is
withdrawn.

## Independent sources

The supplied sources are the patched IPA and the Java port (treated as one
source, because the port is derived from the IPA), the Android spawn/drop
extract, and the Flash build. Agreement between them is evidence of design
similarity, not corroboration. Agreement between builds derived from each other
adds nothing.

## Known contamination

The patched IPA reportedly contains CydiaSubstrate, libsubstitute, iGameGod, and SideloadSpoofer; effects attributable to those components cannot be assumed to be game behavior. [hypothesis: IPA]
